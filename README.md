# YewForge

Static public website for Nivren and related work.

## Current product status

- **Nivren:** in active development.
- **Nivren Home (NivDroid):** internal test build; no public build.
- **NivKode:** version 0.1.0 RC5; RC6 work is in progress. It is not released. Public launch is scheduled for 2 November 2026.
- **NivMac:** direction; no public build.
- **Nivren Quark:** planned.

NivKode includes a desktop GUI, CLI/TUI and accessibility themes. Its source licence is AGPL-3.0-only. The Harmony contributor licence agreement is a draft and is not operative.

## Site sections

- `index.html` — current product and research summary
- `nivren.html` — Nivren product status and engineering links
- `press/` — descriptions, status and evidence limits
- `engineering/` — Nivren technical journal
- `the-inconvenience/` — editorial publication
- `privacy.html`, `contact.html` and `support.html` — site information

Research reporting follows deterministic and model-rated evidence boundaries. Must-change is **NOT CONFIRMED**; route-quality R0/R1 are **INCONCLUSIVE**. Model-rated exploratory or inconclusive reviews are not presented as human ratings.
