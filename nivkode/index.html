In the desktop app, choose where a conversation goes

Local model. In the desktop app, new conversations start on a local model when one is installed.

External provider. When a conversation uses Codex, NivKode sends that conversation to the provider of your signed-in Codex account (for example OpenAI or Amazon Bedrock), under your own account. Codex is the one we have run so far, and it is experimental. Claude and Grok are not yet tested.

When a run's outcome is unknown, NivKode says so instead of assuming tests passed.

What we are building.

  • Desktop app. A desktop app remains a development goal. In it, new conversations start on a local model when one is installed. Defaults in other clients vary.
  • Command-line tool and terminal view. Command-line and terminal interfaces remain development goals.
  • Review gate. We are evaluating workspace controls and approval flows in a review candidate. Human review and release approval are pending.
  • Accessibility themes. We are evaluating reading-font choices, text controls and colour palettes in a review candidate. Human review and release approval are pending.

When a conversation uses Codex, NivKode sends that conversation to the provider of your signed-in Codex account (for example OpenAI or Amazon Bedrock), under your own account.

What we have shown so far.

These are scripted demonstrations from the 0.1.0 RC8 review candidate, using a simulated local provider. They show interface designs, not feature completeness, accessibility, or live-provider results.

What we have and have not tested.

  • NivKode 0.1.0 is a review candidate. Human release approval is still pending and nothing is published yet.
  • NivKode remains in testing; platform and provider results are not reported here.
  • Codex is the one we have run so far, and it is experimental. Claude and Grok are not yet tested.
  • An Android app remains a development goal.
  • The launch date may move if testing finds problems.

Launch target: Friday 13 November 2026; may move if testing finds issues.

We post progress as it is evidenced. Follow progress in Updates.
