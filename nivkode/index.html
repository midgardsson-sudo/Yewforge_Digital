NivKode

A local-first developer environment.

NivKode is a desktop app, a command-line tool and a live terminal view for working with AI coding assistants. Your workspace and history stay on your machine. You bring a local model or your own Codex account; a conversation that uses Codex is sent to OpenAI.

Launch target 2 Nov 2026 AGPL-3.0-only May move if testing finds issues.

What it is

Three ways in, one local gateway.

Desktop app

Connect to your local gateway, then open or start a conversation. The app shows run state and where each response came from.

CLI and live terminal view

A terminal view shows a session's steps, routing, changed files and review status as they arrive.

Local first. Choice always. External by human decision.

In the desktop app, new conversations start on a local model through Ollama when one is installed. If you sign in to your own Codex account (experimental), the desktop app uses it only in conversations where you choose it. Codex asks before it changes your files. A local model can read files in your workspace but can't change them or run commands. Claude is not available.

  • Review gate: Codex works in a read-only sandbox and must ask for your approval before it changes your workspace, and the approval step can't be turned off. The review card lists changed files, diffs, reported tests and pending approval actions.
  • Accessibility themes: reading font choices (including Atkinson Hyperlegible and OpenDyslexic), text size and spacing controls, and colour palettes for colour-blind users and high contrast. Evidence for dyslexia-specific fonts is mixed, so they are optional.
  • Licence: AGPL-3.0-only. The source code is not public yet.

Known limitations

What we have and have not tested.

  • NivKode 0.1.0 is a review candidate. Human release approval is still pending and nothing is published yet.
  • The tested desktop build is Linux x86_64. Other systems have not been tested.
  • Automated smoke tests used a simulated provider. On 6 October, test runs on one machine passed with a live Codex account and a local Ollama model, including an approval request and a real file change. Our AI agents ran them, and we still have to review them.
  • The Android app is a preview that you build yourself. On 6 October two builds passed test runs on one phone, the second including two live Codex turns. Our AI agents ran them, and we still have to review them.
  • The launch date may move if testing finds problems.
