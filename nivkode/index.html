How it works.

  • Local model. A local model can answer questions and read workspace files. We can propose file edits and supported project test and build commands. Changes are shown for review; commands run only after approval.
  • Command-line approvals. Run nivkode approve <conversation> <request> to accept one pending local request by its ID. This command accepts only; it does not prompt or decline requests.
  • Local only. The gateway refuses requests to external AI providers and external second opinions while the switch is on. Turning it on stops active external-provider runs.
