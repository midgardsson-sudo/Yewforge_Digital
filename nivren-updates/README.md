# Nivren public build updates

The archive and manifest list approved public updates only. Unpublished material is not included.

Each update may include its date, title, development status, summary, evidence links and related public release references. Status labels distinguish work in progress, experimental work, blocked or planned work, and released builds. A release candidate is not a public release.

Public entries must use accurate status wording and exclude personal data, credentials, private operational information and unpublished research material.
