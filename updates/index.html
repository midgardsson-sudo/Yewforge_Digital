Product update

2026-10-06

NivKode 0.1.0 review candidate: 6 October update

NivKode 0.1.0 is a review candidate. RC17, from 5 October, is our latest numbered candidate. A second verification pass rebuilt it from a clean checkout: two builds produced byte-identical archives, 121 Rust tests and 25 Node tests passed, and an automated scan of 128 accessibility combinations reported no axe violations. On 6 October we merged more work into the next candidate: notes on files and tasks, a read-only worker roster that shows UNKNOWN rather than guess, delivery states that wait for the provider’s own record, a Stop button for a running turn, local or Codex, plain-language error messages, and installer and security hardening. In the desktop app, new conversations now start on a local model when one is installed, and an external provider is used only in conversations where you choose it. Test runs on one machine passed with a live Codex account and a local Ollama model after a clean install, and our Android app passed test runs on one phone, the second including two live Codex turns. Our AI agents ran these checks and test runs, and we still have to review them. Human review, release approval and publication are pending. Our target for the public release is 2 November 2026, and it may move if testing finds issues. Correction to our 3 October entry: automated tests run on every release candidate, not on every change, and the NivKode source code is licensed AGPL-3.0-only but is not public yet.

Product and research update

2026-10-04

NivKode 0.1.0 RC8 is a review candidate

NivKode 0.1.0 RC8 is a review candidate. Release approval and publication are pending. Linux x86_64 install evidence used a fake local provider; it does not establish live-provider acceptance. No Android physical-device acceptance is claimed. The launch target remains 2 November 2026 and may move if testing finds issues. We also corrected our own research records: some ratings we'd labelled as human were made by an AI model. Those results stay inconclusive, and we've tightened our rules so it can't happen again. Honest results matter more than good-looking ones.

Product and research update

2026-10-03

NivKode 0.1.0 RC6 is ready for testing

NivKode 0.1.0 RC6 is ready for testing: a desktop app alongside the CLI and live terminal view, dyslexia-friendly and colour-blind-safe themes, and free automated tests on every change. Open source (AGPL-3.0), launching 2 November. We also corrected our own research records: some ratings we'd labelled as human were made by an AI model. Those results stay inconclusive, and we've tightened our rules so it can't happen again. Honest results matter more than good-looking ones.
